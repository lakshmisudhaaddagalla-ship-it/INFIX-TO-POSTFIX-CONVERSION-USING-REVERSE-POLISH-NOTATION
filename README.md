# INFIX-TO-POSTFIX-CONVERSION-USING-REVERSE-POLISH-NOTATION
This C project converts infix expressions (like A+B) to postfix notation (like AB+) using a LIFO stack, handling operator precedence and associativity across modular files (header.h, main.c, pushpop.c, precedence.c, convert.c) built with a Makefile.
